Tetorial:

structuur

In dit project gaa je zelf het spel memory programmeren. Om dit te doen heb je het programma visuele studio code nodig en de extentie Live server. Dit is een extensie die je kan downloaden in de extensie store van visual studio code. Deze extensie zorgt ervoor dat je de website kan bekijken in je browser. Je kan dit doen door met de rechtermuisknop op het index.html bestand te klikken en dan op open met live server te klikken. Je kan ook op de play knop bovenin klikken. Als je dit gedaan hebt zie je dat er een tabblad opent in je browser met de website. Je kan nu aan de slag gaan met het maken van het spel memory. Je kan de bestanden die je nodig hebt vinden in de folder structuur. Deze folder structuur is al voor je aangemaakt. Je kan deze downloaden door op de knop hieronder te klikken.

In de folder structuur zie je een aantal mappen. Css hier in zitten je css bestanden. imgage hier in zitten je afbeeldingen. scripts hier in zitten je javascript bestanden. index.html dit is het hoofdbestand van je website.

Linken van CSS en JS

Wanneer je een website bouwt, wil je meestal de stijl (CSS) en het gedrag (JavaScript) van je pagina scheiden van de structuur (HTML). Dit zorgt voor overzichtelijke, onderhoudbare en herbruikbare code. Daarom link je externe bestanden aan je HTML-bestand in plaats van alles in één bestand te schrijven.


Met CSS (Cascading Style Sheets) geef je je website kleur, lay-out en stijl. In plaats van de CSS rechtstreeks in je HTML te zetten, kun je beter aparte .css-bestanden gebruiken. Je voegd dit bovenaan in de head toe.

<link rel="stylesheet" href="./css/nav.css" /> <link rel="stylesheet" href="./css/main.css" />


JavaScript zorgt voor interactiviteit, zoals menu’s die uitklappen of formulieren die worden gevalideerd. Net als bij CSS kun je het script in een apart bestand zetten. Je voegd dit toe onderaan in de body tag.

<script type="module" src="./scripts/main.js"></script>

players

In dit onderdeel houd je bij welke speler aan de beurt is en wat hun score is. Je gebruikt hiervoor HTML-elementen zoals <p> en <span>, zodat je deze later via JavaScript eenvoudig kunt aanpassen.


De id's zoals player1, player2 en current-player gebruik je in JavaScript om scores en de beurt dynamisch te kunnen wijzigen tijdens het spel. Je plaats dit stuk code in een section tag.

<div> class="players"> <p>Player <strong>1</strong>: <span id="player1">Score: 0</span></p> <p>Player <strong>2</strong>: <span id="player2">Score: 0</span></p> <p id="current-player">Player 1's turn</p> </div>

cards

Hier maak je de speelkaarten van het memoryspel aan. Elke kaart bestaat uit een voor- en achterkant. De achterkant is standaard zichtbaar, de voorkant wordt pas getoond wanneer de speler op een kaart klikt.

Elke kaart ziet er ongeveer zo uit:

<div class="memory-cards" data-card="html"> <img class="back" src="./image/back.png" alt="back" /> <div class="front hidden"> <img class="card" src="./image/html.png" alt="HTML" /> </div> </div>

Dit is maar 1 kaartje zorg ervoor dat je er in het totaal 8 hebt. je moet dan wel nog de "src" aanpassen dit id de link naar de juiste afbeelding, Je moet ook de alt aanpassen met een beschriveing van de afbeelding dat als de afbeelding niet word gevonden deze tekt word getoont.

Na Html en CSS is het tijd voor JavaScript. JavaScript zorgt voor het dynamische in jouw website.
