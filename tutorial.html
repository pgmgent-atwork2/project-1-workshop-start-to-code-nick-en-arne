structuur

In dit project gaa je zelf het spel memory programmeren. Om dit te doen heb je het programma visuele studio code nodig en de extentie Live server. Dit is een extensie die je kan downloaden in de extensie store van visual studio code. Deze extensie zorgt ervoor dat je de website kan bekijken in je browser. Je kan dit doen door met de rechtermuisknop op het index.html bestand te klikken en dan op open met live server te klikken. Je kan ook op de play knop bovenin klikken. Als je dit gedaan hebt zie je dat er een tabblad opent in je browser met de website. Je kan nu aan de slag gaan met het maken van het spel memory. Je kan de bestanden die je nodig hebt vinden in de folder structuur. Deze folder structuur is al voor je aangemaakt. Je kan deze downloaden door op de knop hieronder te klikken.

JS

Na Html en CSS is het tijd voor JavaScript. JavaScript zorgt voor het dynamische in jouw website. Je ziet dat je in jouw folder structuur 3 bestanden. main.js is het hoofdbestand, in dit bestand komt alle andere code samen. shuffle.js zorgt ervoor dat de kaarten geschud worden. flipCard.js zorgt ervoor dat de kaarten omgedraaid worden.

kaartjes draaien

Nu ga je de code schrijven die je kaartjes laat draaien als je er op klikt. Je begint door naar het bestand flipCard.js te gaan.

In dit bestand ga je beginnen door de functie flipCard() te schrijven. In deze functie voeg je ook variabelen toe. De eerste variable zorgt er voor dat alle html die onder de classe memory-cards vallen geleselecteerd worden. De tweede variable zorgt ervoor dat de eerste kaart die je omdraait opgeslagen wordt. De derde variable zorgt ervoor dat de tweede kaart die je omdraait opgeslagen wordt.

export default function flipcard() { const $memoryCards = document.querySelectorAll(".memory-cards"); let firstCard = null; let secondCard = null; }

Nu ga je in de functie flipCard een forEach loop maken die over alle kaarten heen loopt. In deze loop ga je een event listener toevoegen die ervoor zorgt dat de kaart omgedraaid wordt als je er op klikt. Als er op een kaart geklikt wordt dan controleren we of de kaart de klasse hidden bevat. Als dit het geval is verwijderen we de klasse hidden. Indien de kaart klasse niet had stoppen we de functie

$memoryCards.forEach((memoryCard) => { memoryCard.addEventListener("click", function () { if (this === firstCard) return; const front = this.querySelector(".front"); const back = this.querySelector(".back"); if (!front.classList.contains("hidden")) return; front.classList.remove("hidden"); back.classList.add("hidden"); }); });

We kunnen nu de kaarten omdraaien maar we willen dat er maar 2 kaarten omgedraaid worden. We doen dit door de variable lockboard toe te voegen. Deze zorgt er voor dat het bord vastegest wordt. We controleren of er al een eerste kaart is geselecteerd. Als dat niet het geval is, stel de eerste kaart in op de huidige kaart en stop de functie. Als er al een eerste kaart is, stel de tweede kaart in op de huidige kaart. Dit betekent dat er nu twee kaarten zijn omgedraaid

Met deze code kan je nu 2 kaartjes draaien

export default function flipcard() { const $memoryCards = document.querySelectorAll(".memory-cards"); let firstCard = null; let secondCard = null; let lockBoard = false; $memoryCards.forEach((memoryCard) => { memoryCard.addEventListener("click", function () { if (lockBoard) return; if (this === firstCard) return; const front = this.querySelector(".front"); const back = this.querySelector(".back"); if (!front.classList.contains("hidden")) return; front.classList.remove("hidden"); back.classList.add("hidden"); if (!firstCard) { firstCard = this; return; } secondCard = this; lockBoard = true; }); }); }

controleren

Nu dat we kaartjes kunnen draaien gaan we de code schrijven om kijken of de kaartjes machten. Hiervoor gaan we 4 functies moeten schrijven 1 om te kijken of de kaarten dezelfde zijn. 1 om de kaarten vast te zetten als ze het zelfde zijn. 1 om de kaarten terug om te draaien als ze niet het zelfde zijn en 1 om het bord te resetten.

kaarten machten

De eerste functie die we gaan schrijven is de functie checkForMatch(). Deze functie gaat kijken of de kaarten dezelfde zijn. Dit doen we door te kijken of de data-card van de eerste kaart gelijk is aan de data-card van de tweede kaart. Als dit het geval is, roepen we de functie disableCards() aan.

function checkForMatch() { if (firstCard.dataset.card === secondCard.dataset.card) { disableCards(); } else { } }

De kaarten vastzetten

De tweede functie die we schrijven is de functie disableCards(). Deze functie zet de kaarten vast als ze gelijk zijn. Dit doen we door de klasse disabled toe te voegen. Hierdoor blijven de kaarten vast staan en zijn ze niet meer aanklikbaar. Daarna resetten we na 1 seconde het bord en kunnen we terug verder spelen.

function disableCards() { setTimeout(() => { firstCard.classList.add("disabled"); secondCard.classList.add("disabled"); resetBoard(); }, 1000); }

Kaarten terugdraaien

De derede functie is al een complexere functie. Deze vindt je terug in bibliotheek.js en plaats je onder disableCards.js. Deze functie roep je aan de functie checkForMatch

function checkForMatch() { if (firstCard.dataset.card === secondCard.dataset.card) { disableCards(); } else { unflipCards(); } }

het bord resseten

De vierde functie die we schrijven is de functie resetBoard(). Deze functie reset het bord. Dit doen we door de eerste en tweede kaart weer op null te zetten. Hierdoor kunnen we terug verder spelen.

function resetBoard() { firstCard = null; secondCard = null; }

score bord

Nu dat we de kaarten kunnen draaien en controleren of ze gelijk zijn, gaan we de score bijhouden. Hiervoor gaan we een scorebord maken. We voegen eerst 2 variabelen toe aan de functie. De eerste zorgt dat de eerste speler begint en de tweede is een object dat de score bij houdt.

let currentPlayer = 1; let scores = { player1: 0, player2: 0, };

Nu dat we de score bijhouden, moeten we de score ook weergeven. Hiervoor maken we de functie updateUI(). Deze staat in de bibliotheek.js kan je plaatst deze functie onder de variabelen. Je roept deze functie aan in checkForMatch() en na resetBoard()

function checkForMatch() { if (firstCard.dataset.card === secondCard.dataset.card) { disableCards(); scores[`player${currentPlayer}`] ++; } else { unflipCards(); switchPlayer(); } updateUI(); } /* ... */ function resetBoard() { firstCard = null; secondCard = null; } updateUI(); }

We gaan nu de code schrijven om van speler de veranderen deze code verandert zorgt er voor dat speler 1 verandert naar speler 2 en omgekeerd. Deze functie roep je aan in checkForMatch. Als er twee verschillende kaarten zijn aangeduidt

function switchPlayer() { currentPlayer = currentPlayer === 1 ? 2 : 1; }

schudden

Nu de kaarten omgedraaid worden en de score bijgehouden worden is het tijd om de kaarten de schudden. Deze code is complex en vindt je terug in bibliotheek.js. Je plaats de code in het bestand shuffle.js. Deze code zorgt ervoor dat de kaarten geschud worden en dat ze in een random volgorde komen te staan.

main.js

Je zal gemerkt hebben dat aan het begin van de functies "export default" staat dit zorgt er voor dat we functies in andere bestanden kunnen oproepen. We doen dit vooral om een goed overzicht te houden. Nu we allebei de functies gemaakt hebben gaan we ze oproepen in main.js. We doen dit aan de hand van import

We importeren de functies die we nodig hebben. We importeren shuffleCards() en flipCard(). Deze functies zorgen ervoor dat de kaarten geschud worden en dat de kaarten omgedraaid worden.

import shuffleCards from "./shuffle.js"; import flipCard from "./flipCard.js";

Nu we de functies importeren gaan we ze ook aanroepen. Eerst roepen we de functie schuffle() zodat de kaarten altijd geschudt worden aan als we de pagina openen. Daarna roepen we de functie flipCard() aan zodat de kaarten gedraaid worden. De laaste lijn zorgt er voor dat de kaarten geschudt worden als er op de knop gedrukt wordt.

shuffle() flipcard(); document.getElementById("shuffleButton").addEventListener("click", () => { shuffle(); });
