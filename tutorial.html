Tutorial:

structuur

In dit project gaa je zelf het spel memory programmeren. Om dit te doen heb je het programma visuele studio code nodig en de extentie Live server. Dit is een extensie die je kan downloaden in de extensie store van visual studio code. Deze extensie zorgt ervoor dat je de website kan bekijken in je browser. Je kan dit doen door met de rechtermuisknop op het index.html bestand te klikken en dan op open met live server te klikken. Je kan ook op de play knop bovenin klikken. Als je dit gedaan hebt zie je dat er een tabblad opent in je browser met de website. Je kan nu aan de slag gaan met het maken van het spel memory. Je kan de bestanden die je nodig hebt vinden in de folder structuur. Deze folder structuur is al voor je aangemaakt. Je kan deze downloaden door op de knop hieronder te klikken.

📁 Download folderstructuur

In de folder structuur zie je een aantal mappen. Css hier in zitten je css bestanden. imgage hier in zitten je afbeeldingen. scripts hier in zitten je javascript bestanden. index.html dit is het hoofdbestand van je website.

HTML

Linken van CSS en JS

Wanneer je een website bouwt, wil je meestal de stijl (CSS) en het gedrag (JavaScript) van je pagina scheiden van de structuur (HTML). Dit zorgt voor overzichtelijke, onderhoudbare en herbruikbare code. Daarom link je externe bestanden aan je HTML-bestand in plaats van alles in één bestand te schrijven.


Met CSS (Cascading Style Sheets) geef je je website kleur, lay-out en stijl. In plaats van de CSS rechtstreeks in je HTML te zetten, kun je beter aparte .css-bestanden gebruiken. Je voegd dit bovenaan in de head toe.

<link rel="stylesheet" href="./css/main.css" />


JavaScript zorgt voor interactiviteit, zoals menu’s die uitklappen of formulieren die worden gevalideerd. Net als bij CSS kun je het script in een apart bestand zetten. Je voegd dit toe onderaan in de body tag.

<script type="module" src="./scripts/main.js"></script>

players

In dit onderdeel houd je bij welke speler aan de beurt is en wat hun score is. Je gebruikt hiervoor HTML-elementen zoals <p> en <span>, zodat je deze later via JavaScript eenvoudig kunt aanpassen.


De id's zoals player1, player2 en current-player gebruik je in JavaScript om scores en de beurt dynamisch te kunnen wijzigen tijdens het spel. Je plaats dit stuk code in een section tag.

<div> class="players"> <p>Player <strong>1</strong>: <span id="player1">Score: 0</span></p> <p>Player <strong>2</strong>: <span id="player2">Score: 0</span></p> <p id="current-player">Player 1's turn</p> </div>

cards

Hier maak je de speelkaarten van het memoryspel aan. Elke kaart bestaat uit een voor- en achterkant. De achterkant is standaard zichtbaar, de voorkant wordt pas getoond wanneer de speler op een kaart klikt.

Je plaatst de kaartjes in de section tag onder de players.
Elke kaart ziet er ongeveer zo uit:

<div class="memory-cards" data-card="html"> <img class="back" src="./image/back.png" alt="back" /> <div class="front hidden"> <img class="card" src="./image/html.png" alt="HTML" /> </div> </div>

Dit is maar 1 kaartje zorg ervoor dat je er in het totaal 8 hebt. je moet dan wel nog de "src" aanpassen dit id de link naar de juiste afbeelding, Je moet ook de alt aanpassen met een beschriveing van de afbeelding dat als de afbeelding niet word gevonden deze tekt word getoont.

CSS

plaatsing

Met CSS bepaal je de layout van je website. In dit gedeelte wordt de positionering van de knoppen en andere elementen geregeld, zodat alles mooi in het midden van de pagina staat.

.button-container { display: flex; justify-content: center; align-items: center; } /*restart*/ .restart-button { display: inline-block; padding: 12px 24px; text-align: center; text-decoration: none; margin-bottom: 3rem; } /*shuffleButton*/ #shuffleButton { padding: 10px 20px; } /* Speler sectie */ .players { margin: 0 auto 2rem auto; padding: 1rem 2rem; width: fit-content; } /* Memory kaarten */ .cards { display: flex; flex-wrap: wrap; gap: 1rem; justify-content: center; padding: 2rem; } .cards li { flex: 1 0 150px; display: flex; justify-content: center; } .memory-cards { position: relative; perspective: 1000px; } /* Achterkant van de kaart */ .back { z-index: 2; } /* Voorzijde van de kaart */ .card { display: block; margin: 0 auto; } /* Verborgen kaart */ .front, .back { position: absolute; top: 0; left: 0; backface-visibility: hidden; } .hidden{ opacity: 0; pointer-events: none; z-index: 1; }

grote

Deze CSS zorgt ervoor dat de knoppen en kaarten een specifieke grootte krijgen, zodat ze goed passen op de pagina en goed zichtbaar zijn voor de gebruiker.

/*restart*/ .restart-button { font-size: 16px; } /*shuffleButton*/ #shuffleButton { font-size: 1.2rem; font-weight: bold; } /* Speler sectie */ .players { width: fit-content; } .memory-cards { width: 6rem; height: 9rem; } /* Achterkant van de kaart */ .back { width: 6rem; height: 9rem; } /* Voorzijde van de kaart */ .card { max-width: 5.5rem; max-height: 8.5rem; } .front{ width: 6rem; height: 9rem; } /* Verborgen kaart */ .front, .back { width: 6rem; height: 9rem; }

decorate/animatie

CSS animaties zorgen ervoor dat elementen, zoals knoppen, een visuele interactie hebben met de gebruiker, zoals wanneer een knop wordt ingedrukt of wanneer de muis eroverheen beweegt.

/*restart*/ .restart-button { text-decoration: none; background-color: #4CAF50; color: white; border-radius: 5px; border: none; transition: background-color 0.3s, transform 0.2s; } .restart-button:hover { background-color: #45a049; transform: scale(1.05); } .restart-button:active { background-color: #388e3c; } /*shuffleButton*/ #shuffleButton { background-color: #35ff2b; color: #fff; border: none; border-radius: 12px; text-transform: uppercase; cursor: pointer; transition: transform 0.3s ease, background-color 0.3s ease, box-shadow 0.3s ease; box-shadow: 0 4px 8px rgba(0, 0, 0, 0.2); } #shuffleButton:hover { background-color: #2d9c1b; transform: scale(1.05); box-shadow: 0 6px 12px rgba(0, 0, 0, 0.3); } #shuffleButton:focus { outline: none; box-shadow: 0 0 10px #35ff2b; } /* Speler sectie */ .players { color: #35ff2b; border-radius: 12px; } /* Memory kaarten */ .cards { list-style: none; } /* Achterkant van de kaart */ .back { border: 3px solid #000; border-radius: 8px; box-shadow: 0 0 10px #35ff2b88; cursor: pointer; transition: transform 0.3s ease; } /* Voorzijde van de kaart */ .card { border-radius: 8px; transition: transform 0.3s ease; } .front{ background-color: #000; border: 3px solid #000; border-radius: 8px; box-shadow: 0 0 10px #35ff2b88; } /* Verborgen kaart */ .front, .back { transition: opacity 0.5s ease; border-radius: 8px; } .hidden{ opacity: 0; pointer-events: none; z-index: 1; }
